# Object Detection from Drone Video

CIS 5810 Final Project, Group 5. Detecting PFM-1 mines in drone imagery (IARC Mission 10).

## Baseline: Grid CNN

| mAP@50 | Precision | Recall | F1 |
|---|---|---|---|
| 55.3% | 77.0% | 52.2% | 62.2% |

## Run

1. Upload `dataset_10pct.zip` to the root of My Drive.
2. Open [`detector.ipynb` in Colab](https://colab.research.google.com/github/pranavgupta55/5810FinalProject/blob/main/detector.ipynb), select a T4 GPU, and choose Run all.
